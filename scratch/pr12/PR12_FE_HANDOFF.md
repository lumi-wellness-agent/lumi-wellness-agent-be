# PR-12 FE 인계

PR-11의 진행률 기반 보행 타이머 구조를 재사용하고, PR-12 전용으로 좋은 점 3가지 알아차림 입력을 추가했습니다.

- 기본 시간: PR-12 원본 기준 30분
- 개발 테스트: 30초·60초
- GPS·DeviceMotionEvent: 사용하지 않음
- 안전 확인 후 시작
- 목표 도달 후 자동 종료하지 않음
- `noticing.items`에 최대 3개의 기록 저장
- 부분 저장과 수정이 가능한 구조
- `recorded_count`로 실제 작성 개수 표시

## 음성 가이드

`pr12-runtime.json`의 `voice_guide`에 한국어 문구와 0·30·60·90·100% 시점을 둡니다. 사용자가 시작 전에 음성 사용과 음량을 선택하며, 실행 상태가 `RUNNING`일 때만 한 구간당 한 번 재생합니다. 재생한 퍼센트는 `localStorage`의 `voicePlayed`에 저장하여 새로고침 중복을 막습니다. 음성 API가 없거나 재생에 실패하면 화면의 `voiceNotice` 텍스트로 대체합니다. 목표 시점을 한 번에 지나가도 한 interval에 한 문구만 처리합니다.

모바일 브라우저는 화면 잠금·백그라운드 전환 중 `speechSynthesis` 재생이나 예약 콜백을 보장하지 않습니다. 사용자는 안전한 장소에서만 조작해야 하며, 음성을 듣지 못해도 타이머와 기록 기능은 계속 사용할 수 있습니다. 시점과 문구는 연구적으로 검증된 개입 시점이 아닌 프로토타입 UX 제안입니다.

원본 PR-12 JSON은 수정하지 않았습니다. 결과의 보행 여부는 자기보고이며 알아차림 기록 수와 활동 완료 여부는 동일한 값으로 취급하지 않습니다.

```powershell
..\\..\\.venv\\Scripts\\python.exe -m http.server 8781
```
