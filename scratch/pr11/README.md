# PR-11 야외 자연 보행 웹 프로토타입

원본 `data/protocols/PR-11.json`의 기본 시간 50분과 야외 활동 조건을 반영한 로컬 MVP입니다. 시작 전 환경·몸 상태를 확인하고, 타이머와 진행률을 표시하며, 현재 버전에서는 활동 후 자기보고를 수집하지 않습니다. GPS·센서·서버 저장은 사용하지 않습니다.

## 실행

PowerShell에서 이 폴더로 이동한 뒤 다음을 실행합니다.

```powershell
.\.venv\Scripts\python -m http.server 8767
```

브라우저에서 `http://localhost:8767/index.html`을 엽니다. `file://` 직접 열기 대신 HTTP 서버를 사용하세요.

## 데이터와 복구

진행 상태와 결과는 브라우저 `localStorage`의 `lumi.pr11.outdoor.v1` 키에 저장됩니다. 새로고침 후 진행 상태가 복구되며, 서버의 공식 기록으로 간주하지 않습니다. 결과 화면의 JSON은 FE 연동용 형태를 확인하기 위한 것입니다.

타이머는 `Date.now()` 차이를 이용하므로 백그라운드 전환·화면 잠금 뒤 복귀 시에도 interval 호출 횟수에 의존하지 않습니다. 일시정지 중에는 경과 시간이 증가하지 않습니다.

일반적인 목표 전 종료는 실행 계약상 허용하지 않으며, 안전 또는 불편 중단만 결과에 기록합니다. 안전 중단 사유는 `SAFETY`, 불편 중단 사유는 `DISCOMFORT`입니다.

시작 전에는 `walking_environment`와 `body_condition`을 확인합니다. 두 조건을 모두 확인해야 활동을 시작할 수 있으며, 이 체크는 사용자의 자기확인 기록이지 서비스의 안전 판정이 아닙니다.

활동 중에는 “화면을 계속 바라보기보다 타이머를 가끔 확인하며 주변의 자연물을 보세요.”라는 고정 문구만 표시합니다. 활동을 마친 사용자는 `완료`를 누르고, 안전이나 불편으로 중단하려면 `중단`을 누른 뒤 확인창에서 `중단하기`를 선택합니다. 결과 화면에는 실제 보행 여부와 개인별 효과를 자동으로 확인하거나 검증하지 않는다는 안내를 표시합니다.

시작·활동 중·목표 도달·중단 확인·결과 한계 문구는 `PR-11.proposed.json`의 `content_spec.slots`에서 읽어 출력합니다. FE는 `phase`에 맞는 슬롯을 찾아 표시하며 문구를 직접 하드코딩하지 않습니다.

슬롯 문구가 없으면 `fallback_text`를 사용합니다. TTS는 시작 버튼 직후와 진행률이 처음 100%가 된 순간에만 재생합니다.

목표 시간 전에는 종료 버튼이 `중단`으로 표시되고, 목표 시간에 도달하면 `완료`로 바뀝니다. 중단 사유는 `SAFETY` 또는 `DISCOMFORT`로 기록하며, 정상 완료 시 `stop_reason`은 `null`입니다. 새로고침이나 일시정지 복구 시에는 `PAUSED` 상태를 유지하고 사용자가 `재개`를 눌러야 활동을 이어갑니다. 종료 후 결과 화면에는 목표 달성 여부와 `다시 시작`만 표시합니다.

목표 시간에 도달하면 경과 시간과 진행률을 그 시점에 고정하고 `완료`만 활성화합니다. 실행 결과의 `phase_history`에는 확인 완료, 시작, 일시정지, 재개, 목표 도달, 완료, 중단 이벤트를 기록합니다.

## 향후 만보기 확장 지점

정상 완료 결과 예시는 `pr11-result.completed.example.json`, 안전·불편 중단 결과 예시는 `pr11-result.example.json`입니다.

결과 JSON의 `estimated_steps: null`, `automatic_walking_verification: "not_performed"` 필드와 타이머 상태 객체를 유지해 센서 지원 여부, 권한, 추정 걸음 수, 신뢰도 필드를 추가할 수 있습니다. 현재는 센서 권한을 요청하지 않습니다.
