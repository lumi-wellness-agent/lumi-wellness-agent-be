# PR-18 설계 제안

원본 프로토콜의 연구 근거와 duration 정의는 보존한다. 서비스 권장 시간은 15분으로 제안하되, 타이머 도달과 활동 완료를 분리한다.

## 프로세스
`INTRO → WRITING ↔ PAUSED → COMPLETED`; 별도 글쓰기 시작 버튼은 제공하지 않는다. 사용자가 첫 텍스트를 입력하는 순간 타이머를 시작한다. 실제 타임스탬프로 경과 시간을 계산하되 화면에는 진행률과 남은 시간을 표시하지 않는다. 15분은 내부 권장·기록 기준이며 완료 조건이 아니다. 최소 300자 작성 후 사용자가 완료를 확정한다.

## 데이터·개인정보
작성 내용, 수정 시각, 타이머 값은 별도 필드로 저장한다. MVP는 브라우저 임시 저장만 사용하며 내보내기·삭제를 제공한다. 서버 전송과 분석은 범위 밖이다.

입력 후 500ms 지연 방식으로 임시 저장한다. 새로고침은 내부 로그에만 기록하고 타이머를 `PAUSED`로 전환한다. 복구 범위는 작성 텍스트, 내부 경과 시간, 활동 완료 여부로 제한한다. 복구 후 사용자가 다시 입력하면 타이머를 재개하고, 복구된 글이 300자 이상이면 완료 버튼을 활성화한다. 브라우저 종료와 예상하지 못한 오류는 `STOPPED`로 기록하고 오류 종류·메시지는 내부 로그에만 남긴다. 완료 저장은 idempotency로 중복 생성하지 않는다.

## 확정/제안
- 확인 사실: 원본 duration·eligibility·constraints·연구 근거.
- 확정된 서비스 제안: 화면 타이머 숨김, 기본 권장 15분, 최소 300자, 사용자 완료 확인.
- 제안: 프롬프트 문구, 5,000자 제한, 30/60초 테스트 모드, localStorage 복구.
- 제외: 개인정보 보관 기간·삭제·내보내기 기능은 현재 범위에 포함하지 않는다.
- 검토 필요: 프롬프트의 연구 출처와 텍스트 보존 정책.
