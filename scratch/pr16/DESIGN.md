# PR-16 설계 제안

원본 `data/protocols/PR-16.json`의 연구 근거와 활동 정의는 변경하지 않는다. 이 문서는 웹 실행 계약만 제안한다.

## 프로세스
PR-16은 독립 시간 활동이 아니라 호스트 활동에 삽입되는 팝업 입력 모듈이다.

호스트 활동의 특정 시점에 팝업을 표시한다.

`HOST_ACTIVITY_RUNNING → PR16_POPUP_READY`.

팝업에서 `건너뛰기`를 누르면 PR-16을 저장하지 않고 호스트 활동으로 복귀한다. `진행하기`를 누르면 3개의 입력 칸을 표시한다.

`PR16_POPUP_READY → PR16_INPUTTING → PR16_COMPLETED`.

최소 1개 입력은 유효해야 하며, 나머지 칸은 비워둘 수 있다. 각 입력은 1~3단어, 최대 20자의 짧은 구로 제한한다. 완료 버튼을 누른 뒤 검증하고, 실패하면 입력 화면에 오류를 표시한다.

PR-16에는 타이머를 두지 않는다. 시간은 호스트 활동이 관리하며, PR-16 결과에는 시간 도달이나 진행률을 완료 조건으로 사용하지 않는다.

검증 통과 후 결과를 별도 저장하고 팝업을 닫는다. 호스트 활동의 화면과 타이머는 일시정지하지 않는다. 새로고침은 별도 중단 버튼 없이 호스트와 PR-16을 `STOPPED`로 기록한다. 감정 진단·점수화·치료 효과 평가는 적용하지 않는다.

## 확정/제안 구분
- 확인 사실: 원본 프로토콜의 연구 근거·duration·eligibility·constraints는 원본을 참조한다.
- 확정된 제안: 3개 입력 칸, 최소 1개 유효 입력, 각 1~3단어·최대 20자, 완료/건너뛰기/중단 분리, 별도 기록.
- 통합 시 결정: 어떤 호스트 노드에서 호출할지와 복귀 대상.
- 추가 검토: 개인정보 보존 기간, 서버 저장 여부.
