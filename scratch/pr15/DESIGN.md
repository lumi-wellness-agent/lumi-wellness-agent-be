# PR-15 자연 생명체 컬러링 설계 제안

원본 `data/protocols/PR-15.json`의 실험적 활동 정의와 연구 근거는 수정하지 않는다.

## 프로세스

도안 1개를 표시하고, 첫 유효 색칠 영역 클릭 시 내부 시간을 기록한다. 화면에는 타이머 대신 색칠 진행률과 남은 영역 수를 표시한다. 모든 색칠 가능 영역을 한 번 이상 채운 뒤 사용자가 완료 버튼을 눌러 활동을 종료한다.

## 기능 범위

- 8색 고정 팔레트
- 영역 재색칠 허용
- 검은 외곽선 클릭 무시
- 지우개 선택 후 영역 클릭 시 흰색·`uncolored`로 복원
- 전체 초기화와 Undo는 제공하지 않음
- 입력 후 500ms 지연 저장
- 새로고침·창 닫기 후 임시 상태 복구
- 완료 후 임시 캐시 삭제

지우개는 개별 영역을 되돌리는 유일한 수정 기능이다. 마지막 영역 색칠 즉시 자동 완료하지 않고, 완료 버튼을 별도로 제공한다.

## 현재 검증 결과

- 자연물 도안 표시 확인
- 검은 외곽선 표시 확인
- 독립 영역 색칠 확인
- 지우개 기능 정상 작동 확인
- 새로고침·브라우저 뒤로가기 복구 기능은 현재 제공하지 않음
- 현재 선택된 팔레트 색상을 별도로 표시하지 않아 사용성이 제한될 수 있음

## 고도화 제안

현재는 고정 8색 팔레트를 사용하지만, FE 구현 단계에서는 사용자가 직접 색상을 선택할 수 있는 기능을 검토한다.

- HTML color picker를 통한 사용자 지정 색상
- 최근 사용 색상 목록
- 고정 팔레트와 사용자 색상 팔레트의 병행 제공
- 현재 선택된 색상의 이름·색상 코드·시각적 테두리 표시
- 선택 색상과 지우개 모드의 명확한 상태 표시

사용자 지정 색상을 도입하더라도 색칠 영역 상태는 `uncolored`·`colored`로 유지하며, 색상 값은 영역별 표현 데이터로만 관리한다. 색상 선택 기능은 현재 프로토타입 범위가 아닌 FE 고도화 검토 항목이다.
