# PR-17 오감 그라운딩 설계 제안

원본 `data/protocols/PR-17.json`의 활동 정의와 연구 근거는 수정하지 않는다. 이 문서는 웹 실행 계약을 제안한다.

## 프로세스

`INTRO → SIGHT_5 → TOUCH_4 → SOUND_3 → SMELL_2 → TASTE_1 → COMPLETED`.

전체 활동의 권장 시간은 약 10분이다. 감각별 시간 할당은 두지 않으며, 사용자가 각 단계에서 원하는 만큼 머문 뒤 `다음`을 누른다. 10분을 초과해도 자동 종료하거나 실패 처리하지 않는다.

각 감각에서 사용자는 입력 없이 다음 단계로 넘어갈 수 있다. 모든 감각의 숫자를 반드시 채울 필요가 없다는 안내를 계속 제공한다. 전체 단계 중 유효한 입력이 최소 1개 이상 있을 때만 완료를 허용하며, 공백만 입력한 값은 유효한 입력으로 세지 않는다. 냄새·맛 단계에서는 `모르겠음` 또는 `느껴지지 않음`을 입력할 수 있고, 억지로 관찰하거나 기록하지 않아도 된다. 감각 상태를 평가하거나 정답 판정을 하지 않는다.

## 고정 문구

- 시작: 지금 있는 곳에서 주변의 감각을 하나씩 천천히 알아차려 보겠습니다. 정답은 없으며, 떠오르는 만큼만 관찰하면 됩니다.
- 보기 5가지: 지금 눈에 들어오는 것을 다섯 가지 천천히 찾아보세요.
- 느끼기 4가지: 몸이나 피부에서 느껴지는 감각을 네 가지 알아차려 보세요. 바닥의 감촉, 바람, 옷의 느낌처럼 작고 편안한 감각도 괜찮습니다.
- 듣기 3가지: 지금 들리는 소리를 세 가지 찾아보세요. 가까운 소리와 먼 소리를 구분해 보아도 좋습니다.
- 냄새 2가지: 주변에서 느껴지는 냄새를 두 가지 알아차려 보세요. 뚜렷한 냄새가 없어도 괜찮습니다.
- 맛·입안 감각 1가지: 입안에서 느껴지는 감각이나 맛을 하나 알아차려 보세요. 억지로 맛을 느끼려고 하지 않아도 됩니다.
- 종료: 다섯 가지 감각을 모두 찾지 못해도 괜찮습니다. 지금 주변에 주의를 기울인 것만으로 충분합니다.

## 음성·복구·오류

음성은 프로세스 시작 시에만 선택적으로 재생하거나 완전히 끌 수 있다. 각 감각 단계마다 음성을 반복 재생하지 않는다. 음성 재생에 실패하면 텍스트만 표시한다.

새로고침 시에는 localStorage 임시 캐시에 현재 단계, 완료한 단계, 감각별 사용자 입력을 모두 저장한다. 페이지가 정상적으로 로드되면 캐시의 기록을 전부 불러오고, 현재 단계의 안내는 텍스트로 표시한다. 복구 실패나 예기치 않은 오류는 `STOPPED`로 내부 기록하며, 오류 상세는 사용자에게 표시하지 않는다.

사용자가 감각 그라운딩을 완료하면 임시 캐시를 삭제한다. 최종 결과에는 감각별 입력 내용을 별도로 저장하지 않고, 단계 완료 여부와 완료 상태만 보존한다.

## 공통 복구 정책

진행 중에는 입력과 현재 상태를 임시 캐시에 저장한다. 새로고침·창 닫기·페이지 이탈 시 마지막 상태 저장을 시도하고, 다음 정상 로드에서 캐시 전체를 복구한다. 브라우저 강제 종료·운영체제 종료·저장소 오류에서는 저장이 보장되지 않을 수 있다.

복구에 실패하거나 예기치 않은 오류가 발생하면 사용자에게 기술적인 오류 상세를 보여주지 않고 내부적으로 `STOPPED`로 기록한다. 정상 완료 시에는 완료 상태를 중복 생성하지 않고 임시 캐시를 삭제한다.

## 완료와 시간

10분은 내부 권장 시간 및 로그 기준이며 사용자에게 권장 시간 문구만 안내한다. 화면에는 진행률·남은 시간을 표시하지 않고, 권장 시간 초과로 종료하지 않는다. `recommended_duration_reached`는 내부 기록용이다. 효과·점수·정답을 평가하지 않는다.

## 검토 필요

- 오디오 파일 또는 `speechSynthesis` 사용 방식
- 단계 건너뛰기 허용 범위
- 새로고침 후 현재 단계 복구 정책
- 냄새·맛을 느끼기 어려운 환경에서의 대체 안내
